# Dev Linktree

Projeto desenvolvido com HTML e CSS para reunir links importantes em uma única página. A aplicação funciona como um cartão de visitas digital, permitindo acesso rápido ao GitHub, LinkedIn, portfólio e demais contatos.

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3

## ✨ Funcionalidades

- Foto de perfil
- Nome e profissão
- Links personalizados
- GitHub
- LinkedIn
- Portfólio
- Contato
- Layout responsivo
- Interface moderna

## 📂 Estrutura do Projeto

```bash
Dev-Linktree/
│
├── index.html
├── style.css
├── perfil.jpeg
└── README.md
```

## 🎯 Como Executar

1. Clone ou baixe o projeto.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.

Praticar a criação de uma página pessoal para divulgação de redes profissionais e projetos, simulando plataformas como Linktree.
